# ⚡ Electronic Store

A modern e-commerce web application built for browsing and purchasing electronic components, modules, and hardware development tools. 

---

## 🚀 Features

* **Product Catalog:** Browse a wide variety of electronic items (Arduino boards, sensors, microcontrollers, capacitors, resistors, and modules).
* **Search & Filter:** Easily find components by category or specifications.
* **Shopping Cart & Checkout:** Add items to your cart, update quantities, and simulate a seamless online shopping experience.
* **Responsive Design:** Fully optimized layout that works smoothly across desktop, tablet, and mobile devices.
