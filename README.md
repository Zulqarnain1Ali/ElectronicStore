# ⚡ Electronic Store (.NET)

A robust e-commerce web application built with **.NET** for browsing, managing, and purchasing electronic components, modules, and hardware development tools.

---

## 🚀 Features

* **Product Catalog:** Browse various electronic components, modules, and microcontrollers.
* **Shopping Cart & Order Management:** Add items to cart, manage quantities, and complete checkout.
* **User Authentication & Authorization:** Secure user login and role management using ASP.NET Core Identity *(if implemented)*.
* **Admin Dashboard:** Manage products, categories, and inventory.

---

## 🛠️ Tech Stack

* **Framework:** .NET (ASP.NET Core MVC / Web API / Blazor)
* **Language:** C#
* **Database / ORM:** Entity Framework Core (SQL Server / SQLite)
* **Frontend:** Razor Pages / MVC Views / Bootstrap / HTML / CSS
